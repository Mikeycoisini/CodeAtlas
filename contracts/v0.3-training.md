# V0.3 训练任务与源码理解题契约

接口前缀 `/api/training`。写请求使用已有 `X-CodeAtlas-Token`、JSON、1 MiB 请求上限。OpenAPI 位于同目录 openapi.yaml。

## 任务

任务含 title、goal、constraints、acceptanceCriteria、tags、sourceIds、questions、status、generationId。创建带 idempotencyKey，更新带 revision。标题必填，至少关联一个可读固定来源。最多六个来源，属于同一快照与索引代次，最多十题。ACTIVE 要求目标、验收条件和完整题目。每次更新生成不可变版本和 definitionDigest。

题目使用稳定 UUID，category 取 CODE_READING、CALL_CHAIN、ERROR_JUDGMENT。format 取 SINGLE_CHOICE、TRUE_FALSE、SHORT_ANSWER。选择题有二至六个唯一 id 的选项，correctAnswer 为选项 id。判断题答案为 JSON boolean。开放题答案为文本。每题保存 prompt、referenceExplanation 和最多五条 hints。

GET task 和历史版本返回作答视图，隐藏 correctAnswer、referenceExplanation、hints，提供 hintCount。GET editor 为作者提供完整内容。此部署面向本机单用户自学。

归档通过 PUT status=ARCHIVED，删除采用软删除。归档和删除后已有尝试可读，停止创建新的尝试。

## 尝试与帮助

开始请求带 idempotencyKey。尝试绑定 taskId/taskRevision/definitionDigest。保存回答 PUT 带 revision 与 answers。每个回答含 questionId、value、skipped，未知题目、重复题目或错误类型返回400。省略题目作为未回答。提交/跳过带 revision、idempotencyKey 与可选 answers。跳过省略 answers 时保留已有草稿。每题 skipped=true 记录为跳过。

状态 DRAFT→SUBMITTED 或 DRAFT→SKIPPED。终态回答、规则结果与 submissionDigest 固定。提交同键同内容可重试。旧 revision 或终态冲突返回409。再次作答创建新尝试。

reveal 请求含 questionId、kind=HINT/REFERENCE、零起点 hintIndex、idempotencyKey。服务端追加事件后返回 content/explanation。提交与揭示锁定同一尝试。提交时冻结 hintViewed/referenceViewed，后续揭示保留原标记。MySQL 通过锁定读取获得当前帮助事件，覆盖默认 REPEATABLE READ 隔离级别。

规则结果为 CORRECT/INCORRECT/UNANSWERED/SKIPPED，source=RULE_BASED。开放题为 NEEDS_REVIEW、source=NOT_ASSESSED。提交后的开放题可追加 rating=UNDERSTOOD/PARTIAL/NEEDS_REVIEW 与 reflection，自评 source=USER_SELF_REPORTED。

## AI

POST /ai/contexts 接受 sourceIds、goal、questionCount=1..5、formats、depth。服务器设置 TRAINING_QUESTIONS。反馈预览通过 POST /attempts/{id}/questions/{questionId}/ai-context，仅接受已提交尝试。可选 sourceIds 是冻结来源的非空子集，服务器构造参考答案、实际回答、原始规则结果及提交摘要。

预览、授权、排队、取消和查询复用 `/api/ai`。operation 缺省兼容 EXPLANATION，新增 TRAINING_QUESTIONS/TRAINING_FEEDBACK，上下文摘要绑定用途。指纹协议版本2。有效期15分钟，上下文24000字符/64KiB，输出4096tokens。拒绝授权产生零上游调用。

出题返回可编辑候选，一至五题，数量与请求相同，题型属于请求范围，服务端分配稳定题目 UUID。保存 generationId 时必须匹配成功的出题用途、快照与代次，至少有一条 VERIFIED 引用仍关联任务。反馈返回 strengths/gaps/explanation/suggestedVerdict/citations/uncertainties，source=AI_ASSISTED。反馈独立保存，规则结果与自评拥有各自来源。

## 历史与恢复

尝试携带冻结题目、答案、结果、帮助记录、自评与 AI 反馈。源码存储不可读时返回 availability=UNAVAILABLE 和固定来源元数据，题目和回答继续可读。

前端使用 trainingTaskId、trainingAttemptId、trainingMode、trainingDraftId、trainingAiGenerationId、trainingQuestionId URL 参数。编辑草稿暂存当前浏览器会话。AI候选追加后允许人工修改，通过显式发布生效。未保存到服务器的会话草稿受浏览器会话生命周期影响。
