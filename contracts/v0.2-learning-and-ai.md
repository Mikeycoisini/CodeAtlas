# V0.2 来源、学习资料与授权契约

所有公开 API 位于 /api，沿用本机会话令牌及 Host/Origin 校验，状态变更要求 JSON，实际请求体最多 1 MiB。路径与位置继续采用 V0.1 的相对路径、文件 SHA-256 和 1-based 行号。

## 来源

POST /sources 接受 snapshotId 及 fileId/symbolId，可指定 generationId、startLine、endLine。服务核对快照、文件、代次、符号归属、文件哈希和实际行范围，再生成稳定来源身份。GET /sources/{id} 返回元数据、片段及 snapshotOutdated。项目更新后，引用仍定位原快照。文件存储和数据库需配套恢复。

## 学习资料

/documents、/knowledge、/cards 均提供 GET 列表、POST 创建和 /{id} 的 GET、PUT、DELETE。搜索 query 匹配标题、内容或标签，limit 默认30，最大100。创建必须携带 idempotencyKey，相同键与规范化内容返回原实体，内容变化返回409。更新必须携带 revision，冲突返回409并保持已有内容。DELETE 软删除。

文档、知识包含 title、body、type、tags、sourceIds、generationId。卡片包含 question、answer、explanation、codeExample、notes、knowledgeId、tags、sourceIds。学习来源最多50个，可跨项目。AI 衍生资料创建时自动附加已校验引用。后续编辑可调整关联来源，原始生成保留完整引用历史。删除知识后，既有卡片保留独立内容并允许编辑原关联，新建关联要求有效知识。

## 授权与生成

1. GET /ai/provider 返回公开配置、configured、maxTokens 与 fingerprint。
2. POST /ai/contexts 使用固定来源或符号选区，冻结问题、深度、用途、来源和最多四轮历史。预览显示实际 contextJson、摘要和模型配置。最多6个来源，完整上下文最多24000 UTF-16字符及65536 UTF-8字节，有效期15分钟。
3. POST /ai/consents 仅记录 contextId 和 ALLOW/DENY。拒绝后的新尝试需要新预览。
4. POST /ai/generations 仅接受 consentId 和 idempotencyKey，一个授权对应一个生成。外发前重新检查授权、有效期、摘要及配置指纹，Python 再次核验摘要、指纹和有效期。
5. GET /ai/generations/{id} 查询 QUEUED、RUNNING、SUCCEEDED、FAILED、CANCELLED。POST /{id}/cancel 取消任务，外发前取消阻止发送，外发后的计算可能继续，迟到结果保持取消状态。发送写入与取消采用同一协调边界。
6. 新追问、新模型配置或新问题重新预览及授权。每次请求独立保存候选，资料保存使用其自己的幂等键。

生成状态和时间持久化，单工作线程及8项有界队列。进程重启把未完成任务标记 FAILED/PROCESS_INTERRUPTED，要求重新授权。API 保留已完成解释，人工内容独立存储。

## 引用与模型边界

结构包含 title、summary、keyPoints、explanation、citations 和 uncertainties。每项引用核对 sourceId 是否属于上下文、原文路径、范围及存储哈希。VERIFIED 代表来源位置校验通过，业务解释的正确性需要人工核对。INVALID 显示原因，界面停止提供定位入口。源码与注释作为分析数据输入，模型请求未配置工具执行能力。

Java 到 Python 仅访问本机 HTTP，使用 X-CodeAtlas-Service-Token。Python 调用供应商时禁用重定向和环境代理，响应最多2 MiB，输出最多4096 tokens。提供商错误映射为受控错误码，外部原始正文及凭据不出现在错误响应。

Python 内部接口为 GET /internal/provider 和 POST /internal/generate。生成请求字段为 requestId、contextJson、contextDigest、providerFingerprint、expiresAt，均不可遗漏。成功返回 result 和 usage。公共 GET /health 仅报告就绪状态和版本。

## 当前源码检查

GET 来源的 currentSourceStatus 为 UNCHECKED。用户通过 POST /sources/{id}/check-current 与空JSON触发当前文件核验。响应包含 sourceId、status、checkedAt、message、snapshotSha256，成功读取时提供 currentSha256。检查最多读取2 MiB，遵守 allowed-roots 并拒绝链接、重解析点、目录越界和特殊文件。结果只表示检查时点，来源和学习资料保持原身份，结果不写入来源历史。
