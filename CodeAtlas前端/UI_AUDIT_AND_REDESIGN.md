## 已实现功能与接口基线

- 项目及分析：`/api/session` 令牌；`GET /projects`、`GET /projects/{id}/snapshots`、`POST /imports`、`POST /snapshots/{id}/index`、`GET /tasks/{id}`、取消、重试、诊断读取。任务轮询间隔 700ms。
- 源码：快照文件分页读取、内容读取、符号搜索与分页、符号直达、局部关系读取。Monaco 使用本地 worker 和只读模式。查询参数保留深链、后退和刷新。
- 学习：`documents|knowledge|cards` 列表、检索、分页、增删改、修订号、草稿、关联来源与当前源码显式核查。AI 提供商、上下文预览、授权、生成轮询、引用验证和保存由现有接口驱动。
- 权限与校验：导入需勾选本地读取授权；AI 有单独的预览同意；表单有字段长度限制和后端校验。不能把这些步骤并入快捷操作。

## B. Design System 规范

- 主题：浅色默认、深色可切换；选择存于 `localStorage`，首次跟随系统偏好。Monaco 随主题切换。
- 色彩：中性灰作为底色、表面、分隔线；靛蓝作为主操作与焦点色；语义色仅用于成功、警告、错误和推断状态。所有组件从 CSS token 取值。
- 排版：界面 12/13/14/16/20/24px；正文和表单不低于 12px，长内容行高约 1.5–1.7；代码使用等宽字体。
- 尺度：4px 基础间距，常用 8/12/16/24px；控件高度 32–36px；圆角 6/8/10px；阴影只用于浮层。
- 基础组件：现有 HTML button、input、select 和 dialog 语义继续使用；通过统一类与 token 规范主、次按钮、搜索、标签、面板、状态和浮层，不增加组件库依赖。
- 可访问性：可见焦点、文本与背景对比、图标按钮名称、键盘关闭弹窗、窄屏无横向溢出、减少动画偏好。

## C. 分页面改造方案

1. 全局框架：带文本的统一侧导航、项目上下文顶栏、主题切换、设计 token；保留所有查询参数导航。
2. 项目和导入：项目选择、快照选择与索引操作保持原接口；调整工具栏和任务状态密度，导入弹窗适配窄屏。
3. 源码与检索：可调节导航及证据面板、清晰的文件/符号 tabs、搜索与空状态；源码只读与定位保持不变。
4. 关系：继续展示真实局部关系及证据跳转；类图、调用图和流程图等缺少完整数据与路由的能力在后续产品迭代实现，当前不制造假图。
5. AI、文档、知识、卡片：沿用现有真实请求与保存逻辑，统一表单、来源卡和状态展示；保留预览授权、修订号、草稿和来源核查。

每完成一个改造阶段运行 `npm.cmd run build`。现有 Playwright 测试需要本地后端及其测试数据环境；若可启动则逐页检查 1440px 与 390px 布局和关键交互。

## D. 本轮实际修改

- `src/ui.css`：主题 token 与桌面、窄屏统一样式，覆盖主导航、项目工具栏、源码、关系证据、导入、AI、学习资料与卡片表单。
- `src/main.tsx`：明确样式加载顺序。
- `src/App.tsx`：带文字的主导航、主题切换及 Monaco 同步、项目初始加载状态、可拖动与键盘调宽的源码面板、导入弹窗 Escape 关闭。
- `tests/ui.spec.ts`：浏览器拦截真实 API 路径的固定响应，检查导航、主题、源码定位、面板调宽、窄屏无横向溢出、学习页和导入弹窗，并生成检查截图。测试替身只存在于测试代码。

## E. 验证结果

- `npm.cmd run build`：通过，TypeScript 和 Vite 构建成功。Vite 仍提示 Monaco 主包较大；这是既有依赖体量，未在本次视觉改造中拆包。
- `npx.cmd playwright test tests/ui.spec.ts --reporter=line`：1 项通过。使用构建产物和拦截 API 完成桌面与 390px 截图检查；截图位于 `test-results/ui-*.png`。
- 原有 `tests/explore.spec.ts` 与 `tests/learning.spec.ts` 依赖运行中的后端、测试数据库及部分 AI 服务，本环境未启动这些服务，因此本轮没有执行真实端到端流程。构建与新增浏览器回归不能替代后端联调。

## F. 尚未解决的问题

- 当前产品没有独立的类图、调用图和流程图数据视图；本轮保留真实局部关系及证据跳转，未展示不存在的图谱操作。
- 旧样式文件仍含历史硬编码颜色。`ui.css` 已统一主视图视觉，后续应按组件迁移并删除被覆盖的旧规则，避免长时间双层维护。
- 深层弹窗的完整焦点约束和 AI 提供商真实联调尚待有后端的环境验证。
