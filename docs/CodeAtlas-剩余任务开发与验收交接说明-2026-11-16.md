## 3. 执行条件与数据边界

工程目录为 D:/CodeAtlas/CodeAtlas后端、CodeAtlas前端、CodeAtlasAI。当前技术路线为 Java21 目标、Spring Boot/JDBC/Flyway/MySQL、React/TypeScript/Monaco、Python/FastAPI。Python 依赖版本查看 requirements.txt，Java 与 npm 版本查看当前构建文件。

使用专用测试库和数据目录。3307 为历史独立 MySQL 实例候选端口，启动前确认占用进程和数据目录。3306/MySQL80 及用户正在使用的库保持其正常工作状态。现有脚本可能包含清库、重置测试服务或停止进程操作，执行前阅读实际内容，按任务身份核实目标。

新导入项目仅作静态读取。需要真实编译或测试时，先核对获授权项目、版本及构建脚本，只在独立练习目录或受控样本副本运行。旧授权限定的公开片段、模型供应商和调用目的需逐项核实。新的私有源码外发或扩大真实模型费用范围，需要获得对应授权。

密钥保留在本机配置中，报告只写提供商、模型及配置是否就绪。应用内部 token、数据库密码、完整私有源码和环境变量全集避免进入日志、截图及提交。每次 AI 请求继续经过产品预览和授权链路。

所有提交、报告、证据与图形来源绑定准确 projectId、snapshotId、generationId、文件哈希、任务版本和提交摘要。重建索引、切换项目、重新生成和清理副本后，历史身份继续可辨认。用户外部结果显示 USER_REPORTED，AI 反馈显示 AI_ASSISTED，运行环境失败与能力判断分别记录。

## 5. T01 启动与交付基线

目标为让当前 Java、Python、前端从各自正常入口工作。检查 AiClient.java、LocalServiceToken.java、CodeAtlasAI/codeatlas_ai/settings.py、local_config.py、run.py 和启动脚本。

- [ ] 核对 IDE 的 Java 工作目录和 Python 解释器。Python 可直接运行 run.py，模型密钥从本机 .env 读取。
- [ ] 验证 Java 先启动、Python 先启动、同时启动，三个场景读取相同内部令牌；文件内容以摘要或一致性布尔值核对。
- [ ] 验证已有显式配置的优先级、空密钥降级、模型配置变化后的重新授权。
- [ ] 检查实际监听进程加载的 class/JAR 时间，避免旧包与新源码混用。
- [ ] 验证浏览器能读取 provider 状态、拒绝授权无生成外发、允许授权可通过本机固定模型完成调用。

验收为从正常入口可复现上述行为，错误能指出配置或连接原因。Java 客户端和 Python 的历史定向测试已通过，最终 IDE 连接及运行包需要本任务补证。共享令牌损坏、非标准部署路径等异常需给出可诊断结果。模型密钥仍由使用者提供。

## 10. T06 分析准确性

在 JavaAnalyzer、黄金样本和 PetClinic 固定版本上建立独立预期。样本至少含 Controller／Service／Repository、继承／接口多实现、重载、构造器、缺依赖、语法错误、事务注解和动态装配。

记录文件／符号／关系数量、各类别及状态分布、无法解析原因、抽样规则与样本分母。逐项保存人工或独立基准预期、实际结果、源码范围和差异。确认目标是否静态可判定，运行时未知继续保留未知。当前事务规则覆盖方法显式注解，类级及组合注解扩展需单列规则和测试。

验收报告区分基准自动核对、独立 reviewer 核对和人工核对。阶段计划未要求所有结果必须由用户签字；有能力的独立 reviewer、可信预期和可复核源码可以构成对应范围证据。外部安全或专业认证另按其实际要求开展。

## 11. T07 真实 AI 语义评估

VERIFIED 引用仅代表位置校验，语义评价单列。固定响应测试用于结构与授权，真实输出需逐条对照。发生模型调用失败、环境故障或上下文截断时保留原因和边界。通过标准在执行前写入样本评估表，缺少充分依据时继续标待核实。
