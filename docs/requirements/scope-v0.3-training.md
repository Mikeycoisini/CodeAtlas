# V0.3 训练首批范围

对应批准设计 `docs/superpowers/specs/2026-11-14-v0.3-training-design.md`。

本批覆盖训练任务管理与源码理解题。提供手工建题、三类理解题、单选/判断/开放题、固定源码来源、任务版本、草稿/发布/归档/软删除、草稿回答、逐题及整次跳过、提交与重试历史、提示/参考答案查看事实、规则判分、开放题自评和个人复盘。

AI 提供显式预览授权的出题候选与已提交问题辅助反馈，支持候选追加和人工编辑，保留源码引用、不确定项与独立的反馈来源。既有解释、知识、文档与卡片兼容。

后续范围包括 V03-03 及之后的代码副本、修改题和执行验证。个人掌握记录按已确认阶段归属 V0.4。最终验收记录位于 docs/reports/v0.3-training-acceptance.md。
