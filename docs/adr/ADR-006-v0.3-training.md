# ADR-006 V0.3 训练首批

状态 已采纳，2026-11-14，依据用户批准的训练设计。

训练采用独立领域表和 V3 增量迁移，复用 JDBC 事务、来源快照、幂等请求和 AI 授权基础设施。任务版本固定题目和来源身份，作答绑定版本，终态提交不可覆盖。揭示与提交串行化，MySQL 默认隔离下以当前读取获得帮助事件。
