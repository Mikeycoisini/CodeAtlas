# CodeAtlas V0.2 实施计划

> 使用 superpowers:executing-plans，在当前会话依次实现并验证。用户已批准详细设计和直接完成开发。

## 目标

交付源码授权解释、引用校验、文档、知识和卡片，并验证真实 DeepSeek 与公开样本的端到端链路。

## 架构与技术

React 通过 Java API 管理学习资料和授权。Spring Boot/JDBC/Flyway/MySQL 保存来源、上下文、授权、生成与学习资料。Python/FastAPI/httpx/Pydantic 负责模型适配与结构约束。

## 设计依据

docs/superpowers/specs/2026-11-14-v0.2-design.md。

## 全局约束

- 来源绑定固定项目、快照、代次、文件哈希和范围。
- 拒绝授权与外发前取消时模型请求计数为零。
- 输入源码预算 24,000 字符与 64 KiB，最多 6 个来源。
- 上下文有效期 15 分钟，模型输出上限 4096 tokens。
- 正文编辑使用 revision，创建和生成使用幂等键。
- V1 迁移文件保持既有版本，新增 V2 迁移。
- 密钥通过本机白名单配置读取，真实调用只使用获授权的公开 PetClinic 片段。

## 审阅关注

- 授权后修改模型、问题、上下文或过期时应拒绝外发。
- 模型返回伪造来源、错误范围或超大响应时应提供明确结果。
- 并发编辑、重复创建和取消后的迟到响应应保留一致状态。
- 切换学习页面和源码版本时，迟到请求与历史导航应保持正确身份。
- AI 服务缺失、异常及应用重启时，手工资料与历史来源应可恢复。
