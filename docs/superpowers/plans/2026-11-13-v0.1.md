# CodeAtlas V0.1 Implementation Plan

> 执行本计划时使用 superpowers:executing-plans，逐项实施并记录验证结果。

## Goal

交付本地 Java 项目导入、不可变快照、可信静态索引和源码探索。

## Architecture

React 通过同源 API 访问 Spring Boot。MySQL 保存元数据和索引，专用文件目录保存源码快照。任务写入独立索引代次并以事务发布。

## Tech Stack

React、TypeScript、Vite、Monaco、Spring Boot、JavaParser、JDBC、Flyway、MySQL。

## Spec

docs/superpowers/specs/2026-11-13-v0.1-design.md

## Global Constraints

- 服务监听 127.0.0.1，快照绑定所有源码证据。
- 导入上限为 20,000 文件、单文件 2 MiB、总内容 256 MiB。
- 导入与索引只读取目标项目。
- 用户已批准设计和开发，直接在本次会话依序执行。

## Review Focus

- Windows 重解析点和源码在扫描中变化时应明确失败。
- 重建、取消及进程重启不得破坏已发布索引。
- 接口多实现、外部依赖和重载不得产生错误确定关系。
- 快照切换和迟到响应不得混淆版本。
- 非 UTF-8 与无 Java 项目应提供可理解反馈。
