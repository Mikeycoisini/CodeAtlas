# V0.4 复习、证据与引导契约

接口采用本机会话token、JSON和1MiB写请求上限。OpenAPI见同目录openapi.yaml。新命令持久化精确响应供同键同内容重试，键跨操作或正文冲突返回409。更新必须提供当前revision。

## 复习

`POST /api/reviews/cards/{id}/enroll`由用户主动加入，首次epoch1，初始due为服务器当前UTC毫秒。创建卡片本身保留普通资料行为。队列支持dueOnly、query、knowledgeId、tag、limit、offset，以due/cardId稳定排序。

`suspend/resume/reset`接受revision、epoch、idempotencyKey。暂停/恢复保留原due，重置创建下一epoch并追加管理事件。实质内容摘要包含question/answer/explanation/codeExample及固定来源身份，个人笔记、标签与知识关联单独处理。内容变化时状态CONTENT_CHANGED，评分需先确认采用新版重新学习。

开始尝试冻结卡片内容、cardRevision、contentDigest、epoch/stateRevision、知识revision及来源。DRAFT只返回问题和来源。PUT保存recalledAnswer，最多4000字符。reveal接受revision与幂等键，冻结原回忆后返回参考答案，状态REVEALED。评分仅从REVEALED接受AGAIN/HARD/GOOD/EASY及最多4000字符reflection。

评分由用户自报，HARD表示费力但正确回忆，失败使用AGAIN。服务器使用固定FSRS6配置，UTC毫秒、明确时钟和关闭fuzzing。DEFAULT_V1采用21个固定参数、保持率0.9、60/600秒学习步长、600秒重学步长及36500天上限。每个事件记录算法、完整配置、指纹、前后状态及库日志。

COMMITTED与SKIPPED为终态。跳过保留回忆和原调度。已揭示回忆正文不可改写。首次成功评分原子保存事件、调度状态、尝试终态、学习证据和判断投影。并行旧尝试返回STALE_REVIEW_STATE，内容变化、删除及暂停返回可恢复冲突。时间早于上次评分时返回CLOCK_MOVED_BACKWARDS。

history支持分页，`GET /api/reviews/events/{id}`可按身份读取任意旧事件。历史卡片/答案/来源由冻结payload提供，卡片软删除后仍可查。旧源码缺失显示不可用。展示时区由前端选择，调度持续以UTC Instant计算。

## 学习证据

`POST /api/progress/evidence`含knowledgeId、sourceType、idempotencyKey。

| sourceType | 其余输入 | 来源 |
|---|---|---|
| REVIEW_RATING | sourceId为成功评分事件ID | USER_SELF_REPORTED |
| TRAINING_RESULT | sourceId为已提交attemptId、questionId | 原RULE_BASED结果及帮助标记 |
| TRAINING_SELF_ASSESSMENT | sourceId为已保存自评ID | USER_SELF_REPORTED |
| PERSONAL_REFLECTION | rating、reflection | 用户独立记录 |
| PRACTICE_SUBMISSION | sourceId为练习提交ID | USER_PRACTICE；仅成果关联，eligible=false |
| PRACTICE_TEST_RESULT | sourceId为用户测试报告ID | USER_REPORTED；PASSED正、FAILED负，ERROR/TIMEOUT不计能力 |

自评rating为UNDERSTOOD/PARTIAL/NEEDS_REVIEW，reflection最多4000字符。服务器提取原题、原答案、判分与时间，拒绝客户端传入verdict及AI能力判定。同一知识/来源类型/来源身份唯一，重复关联返回已有事实。实践提交是用户成果，不单独证明掌握；测试报告为用户提供，CodeAtlas未执行代码。ERROR/TIMEOUT的eligible=false，保留来源语义但不计为能力失败。

卡片已关联知识时，成功复习自动关联尝试开始时冻结的知识revision。用户后来改变卡片关联时，已开始尝试仍归属原知识。手动关联冻结目标知识当前revision，标记USER_ASSOCIATED。

`POST /evidence/{id}/retract`接受非空reason及幂等键，追加撤回事件，原事实保留。知识改版后的旧证据在历史中展示，当前判断依据当前revision。每次证据变更追加mastery_assessment并更新knowledge_progress。

### EVIDENCE_V3 真值表

V3 起实践通过按提交计数：同一提交的多份 PASSED 报告只计一次；历史 `EVIDENCE_V2` 判断保留其原有 rule_version，不重写。

优先过滤已撤回、旧知识revision及无能力判断含义的记录。按事实发生时间、创建时间、同一知识的事务内写入序号、ID稳定排序；同毫秒新记录按写入先后判断。迁移前已有记录缺少可信同毫秒顺序，保留ID作为历史平局规则，不追认其真实先后。迟关联的旧事实仍以事实发生时间为主。跳过、未回答、浏览、环境故障和AI建议保留原来源语义。实践提交的eligible=false，只进入历史与关联展示，不参与掌握判断。

| 条件，按顺序判断 | 状态 |
|---|---|
| 当前版本无有效证据 | NO_EVIDENCE |
| 最新有效证据为AGAIN/HARD、INCORRECT、PARTIAL/NEEDS_REVIEW或FAILED实践测试 | NEEDS_REVIEW |
| 至少两次GOOD/EASY复习，或两个不同attempt中无提交前帮助的CORRECT，或两个不同提交的用户报告通过实践测试 | SUPPORTED |
| 其余有有效记录 | PRACTICING |

SUPPORTED显示“已有支持证据”，同时展示自报复习次数、无帮助正确尝试数、实践通过次数和具体依据。UNDERSTOOD个人反思本身只形成自报记录。带帮助的正确理解题保留为辅助学习证据，原帮助标记不变。AI辅助反馈独立显示。

`GET /progress/knowledge/{id}`返回当前判断、全部关联事实、历史版本数量与投影revision。缓存投影仅当知识revision一致且`rule_version`等于当前规则时复用；旧规则（如`EVIDENCE_V2`）的当前指针在读取时按当前规则重算，不写入新assessment、不移动指针，历史判断保留原rule_version。并发或重复读取得到相同判断。history返回不可变判断版本。mistakes提供已提交的错误/待复盘题目，包含准确attempt/question身份。

## 可选引导

创建接受title200、goal4000、sourceIds最多6个、knowledgeIds最多10个及幂等键。六个步骤ID固定为BUSINESS/SOURCE/PRINCIPLE/CODE/VERIFY/REFLECT。PUT可调整顺序、title、status、notes、advice、reason，六个身份必须构成准确排列。

步骤status取TODO/DONE/SKIPPED。引导状态取ACTIVE/PAUSED/EXITED/COMPLETED。actions支持PAUSE、EXIT、RESUME、COMPLETE、REOPEN，携带revision和幂等键。完成要求六步均DONE/SKIPPED，并分别显示完成/跳过数量。EXIT保留记录，可RESUME，COMPLETED可REOPEN。操作与每次编辑均追加含前后定义的事件。

引导步骤活动不会写入掌握证据。编码/验证步骤可记录用户在外部环境中的说明。所有其他功能可直接访问。

### AI建议

`POST /guides/{id}/ai-context`接受revision及用户选择的sourceIds/knowledgeIds，均为当前引导关联资料的子集。允许空资料，仅以目标和步骤提供建议。选择知识时使用最多1000字符正文摘要及明确的截断标记，加上当前学习判断摘要。预览显示全部实际发送的JSON。

LEARNING_GUIDE复用授权/生成/取消，协议指纹3。有效期15分钟，24000字符/64KiB，最多4096输出tokens。contextJson.guide保存guideId/revision/goal/steps/knowledge，sources为空时引用必须为空。现有解释和训练仍维持其来源语义。

结果包含summary、六个stepId/reason/actionAdvice、citations及uncertainties，服务器验证准确步骤集合。`apply-suggestion`接受revision、generationId、幂等键，要求成功结果、正确用途/guideId及相同guideRevision。采纳只应用建议顺序和建议内容，保存用户完成/跳过、标题和笔记。采纳后人工编辑保留生成来源与总结。

建议过期于当前编辑版本时返回409，保留用户内容。原生成结果可查看，重新准备需再次预览授权。AI失败后手工引导和复习继续可用。
