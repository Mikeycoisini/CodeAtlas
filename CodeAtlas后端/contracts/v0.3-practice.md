# V0.3 代码练习副本与外部验证契约

练习副本从已发布训练任务关联的指定快照创建。`POST /api/practice/workspaces` 接受 `taskId`、`snapshotId`、`idempotencyKey`；来源必须属于同一快照。返回任务版本、快照 ID 和独立本地目录。用户在该目录中用自己的 IDE 修改文件；CodeAtlas 不运行其中的代码。`GET /api/practice/workspaces?taskId=` 列出该任务副本，`GET /api/practice/workspaces/{id}` 读取详情。

`POST /api/practice/workspaces/{id}/submissions` 接受 `idempotencyKey`，读取当时副本的普通文件，拒绝链接和特殊文件，将精确内容复制到不可变身份的提交存档。返回递增提交序号、SHA-256 内容清单摘要、变更文件、原/新文件哈希及文本差异预览。预览可能截断；存档保存完整内容。再次读取提交时会校验存档文件哈希。相同键重试不再创建提交，另一个键创建下一次提交。`GET /api/practice/submissions/{id}` 读取详情。

`POST /api/practice/submissions/{id}/test-results` 接受 `status`（PASSED/FAILED/ERROR/TIMEOUT）、`method`、`environment`、`report`、`idempotencyKey`。结果绑定提交 ID 与内容摘要，来源固定为 `USER_REPORTED`，表示用户提供的外部测试信息，不能表示系统已执行或独立验证。报告上限 16000 字符。相同键重试不重复记录。

`POST /api/practice/submissions/{id}/ai-context` 接受可选 `question`（最多2000）、`depth`（BRIEF/STANDARD/DETAILED）和 `sourceIds`（最多6个，须属于任务冻结来源）。返回 AI 预览上下文，包含任务目标／约束／验收条件、提交序号与内容摘要、变更文件差异、用户测试报告和所选源码。外部报告标记为 `USER_REPORTED`，上下文明确 CodeAtlas 未执行代码。差异每文件最多展示4000字符并标记截断，报告总预览最多6000字符；整体沿用 24,000 字符／64 KiB、15 分钟预览、模型指纹与现有授权生成流程，`operation` 为 `PRACTICE_FEEDBACK`。AI 反馈不改变规则判分、测试报告、学习证据或掌握状态。

`POST /api/practice/workspaces/{id}/close` 接受 `idempotencyKey`，将副本置为 CLOSED 并清理练习目录。已保存的提交存档与外部报告保留，关闭后不能再提交。若文件清理失败，可用相同键重试。调用前应在界面确认，因为未提交的本地修改会被删除。

每个文件上限 2 MiB，最多 20000 个文件，总量上限 256 MiB。创建、提交和报告均要求本机会话 token。快照与原项目不作为练习写入目标；原项目可能在导入后自行变化，练习始终基于指定快照。自动执行不在此契约范围内。
