# ADR-001 V0.1 架构与存储

状态为已采纳，日期为 2026-11-13。

用户批准 React + TypeScript、Spring Boot、JavaParser 和本机 MySQL 8.0 路线。PostgreSQL 是比较过的候选，MySQL 通过复用现有运行环境降低准备成本。

采用本地单用户、单后端进程架构。MySQL 保存项目、快照清单、任务、索引代次、符号、关系和诊断。文件系统保存快照原始字节，发布索引通过事务更新代次指针。前后端按用户要求分别位于 CodeAtlas后端 和 CodeAtlas前端。

Flyway 管理迁移，JDBC 保持任务锁和发布事务可检查。H2 仅作为确定性测试依赖，另用独立 MySQL 8.0.43 实例执行同组集成测试。用户现有 MySQL80 服务的账号权限待提供。

Spring Boot 固定为 3.5.16，编译目标 Java 21，兼容验证使用本机 JDK 24。该系列官方要求 Maven 3.6.3 或更新版本，支持 Java 17 至 25。版本信息核对于实施当日。[Spring Boot 官方要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)

JavaParser / Symbol Solver 固定为 3.27.1，解析级别 Java 21。使用其 AST 与符号解析 API，通过缺依赖、重复类型和编码样本验证边界。前端依赖使用 package-lock.json 固定，Vite 在审计后升级为 7.3.8。[JavaParser 官方入门](https://javaparser.org/getting-started.html)

部署方式、多进程、多用户访问、大型仓库或依赖解析需求变化时复核本决策。后续领域对象依照原有版本计划增量建模。
