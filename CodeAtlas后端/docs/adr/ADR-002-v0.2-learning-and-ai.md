# ADR-002 V0.2 学习资料与 AI

日期为2026-11-14，状态为已实施，依据已批准 V0.2 设计。

## 决策

采用独立 Python/FastAPI 服务封装模型协议，Java 管理来源、授权、任务和学习资料。默认 deepseek-flash，由获授权的账号模型列表验证，支持环境变量切换。凭据通过本机白名单配置引用，Java 使用独立内部令牌。

固定快照来源保留项目、快照、索引代次、文件哈希、符号与行范围。上下文和供应商指纹冻结后授权，生成前再次验证。引用返回 VERIFIED 或 INVALID，同时保留不确定项。

文档、知识、卡片统一存储在 learning_records，kind 约束服务端字段，learning_sources 保存多对多来源，复用事务和乐观锁。其物理表结构集中，未来按实体独立演进需要迁移。AI 生成与人工资料独立保存，重新生成提供新候选。

JDK 使用21目标，当前机器构建使用 E:/jdk24，进程临时目录采用短 ASCII 路径以解决 Windows Unix-domain 管道错误。启动脚本提供当前进程配置。

## 权衡

V0.2 使用有界上下文和本机单用户服务。检索以选定声明、文件头或人工关联来源为范围，业务流程说明受实际提供片段覆盖范围约束。模型事实正确性由用户核对，引用校验提供固定位置证据。完整数据库和快照目录配套备份。
