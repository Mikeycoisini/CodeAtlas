# V0.4.2 公开 GitHub 仓库导入验收

日期 2026-11-15。依据用户确认的实现选择：公开仓库、分支/标签、复用本机 Git CLI。对应 IMP-01 P1。

## 已实现范围

- `POST /api/imports/github`：公开 github.com 仓库根地址，可选分支/标签。
- URL/ref 校验：仅 HTTPS github.com；拒绝其他主机、凭据、查询、片段、非标准端口、子树地址、`git@` 与选项式 ref。
- 受控浅克隆：`--depth 1 --single-branch --recurse-submodules=no`；独立 HOME/XDG、空全局配置、`GIT_CONFIG_NOSYSTEM=1`、禁用 hooks/credential helper/LFS smudge；超时与取消轮询；staging 在成功、失败、取消后清理。
- 复用 `SnapshotScanner`、`completeImport` 与既有索引流水线；快照记录解析后的 commit，`.git` 不进入快照。
- V7 迁移：`projects.source_type`、`tasks.source_type`、`tasks.source_ref`；既有数据默认 `LOCAL`。
- 失败任务按原 URL/ref 重试；同一快照身份重复导入复用已有快照。
- 前端导入弹窗增加“本地目录 / GitHub 仓库”切换、来源授权与限制说明。
