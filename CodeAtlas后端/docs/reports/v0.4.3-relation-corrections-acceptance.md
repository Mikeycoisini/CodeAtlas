# V0.4.3 关系人工修正验收

日期 2026-11-15。依据 EXP-04 P1 与 `docs/adr/ADR-008-relation-corrections.md`。

## 已实现范围

- `relation_corrections` 追加式覆盖层，绑定快照、已发布代次与原始关系。
- 支持 `CORRECTED`、`REJECTED`、`UNCERTAIN`；`CORRECTED` 可修改关系类别或目标文本，必须填写理由，可选来源。
- 原始 `relations` 行、`kind`、`status`、`targetText` 与图边聚合保持不变。
- 关系列表返回 `corrections`、`latestCorrection`、`effectiveVerdict`、`effectiveKind`、`effectiveTargetText`；图谱证据返回修正记录。
- 源码页关系卡片新增“修正关系”弹窗，显示原始值、生效值、最新修正理由/来源/时间和历史。
- 图谱证据面板显示对应修正，并明确图边保持原始分析。
- 幂等写入、代次/关系校验、长度限制和非法内容拒绝。
