## 4. 结论与边界

- 当前固定样本下，查询 P95 均低于 52 ms，无错误；图查询是主要成本（TYPE P95 51.82 ms），符号/分页在 4–23 ms。
- 导入成本主要来自 Git 探测、复制与双重扫描；索引仅 48 ms（小样本）。
- 本轮为**单机、单次基线**，未设验收门槛；不能据此推断大样本、并发或多用户表现。
- 未测量：>132 文件/大仓库、并发用户、失败恢复/取消的耗时分布、磁盘 I/O、浏览器布局 Worker 与 Python 服务资源、P99、长时间稳定性。
- 后续若扩容，建议按同一脚本增加 `--samples` 与更大固定样本，先设门槛再优化；保持功能回归。
