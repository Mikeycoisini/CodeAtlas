## 1. 独立预期测试

在 [JavaAnalyzerTest.java](../../../src/test/java/dev/codeatlas/analysis/JavaAnalyzerTest.java#L78-L261) 新增 `independentExpectationsCoverFrameworkRolesAndUnresolvedTargets`，预期来自 Java 语义而非分析器输出，覆盖：

| 类别 | 固定预期 |
|---|---|
| Controller | `@RestController`/`@GetMapping` 注解、方法返回 `String`、构造器与字段类型、声明行 |
| Service/接口 | `GreetingService` 为 INTERFACE，两个实现类的 `greet(String)` 返回 `String` |
| Repository | `OwnerRepository` 为 INTERFACE，`findByLastName(String)` 返回 `Owner`，父类型 `JpaRepository` 不在索引内 |
| 继承/多实现 | 两个 `implements GreetingService` 关系均为 CONFIRMED |
| 重载/构造器 | `calc(int)` 与 `calc(int,int)` 身份不同、行号不同；两个构造器均识别 |
| 缺依赖 | `MissingType` 不影响其他文件；调用目标保持 UNRESOLVED |
| 错误文件 | `Broken.java` 产生 PARSE_ERROR，其余 9 个文件继续分析 |
| 事务 | `@Transactional` 产生 INFERRED 的 TRANSACTION_BOUNDARY，规则名与注解行正确 |
| 动态目标 | 接口调用同时产生 CONFIRMED 编译声明与 UNRESOLVED RUNTIME_CALL |

结果：**6 项测试，0 失败，0 错误，0 跳过**（1.143s），Surefire XML 见 [java-analyzer-surefire.xml](evidence/planning-followup-2026-11-16/f06/java-analyzer-surefire.xml)。
