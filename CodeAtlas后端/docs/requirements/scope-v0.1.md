# CodeAtlas V0.1 实施范围与验收清单

日期 2026-11-13

依据上级目录 PRD V1.0、总体与步骤实施计划 V1.1、初版技术方案及 PoC 方案。主体实现与固定样本验证已完成，真实业务项目验收待用户提供路径和版本。

## 交付目标

用户导入获授权的本地 Java / Spring Boot 项目，固定源码快照，查看索引进度、失败原因和部分结果，通过文件路径或符号搜索定位源码，并查询带证据状态的局部关系。历史引用始终绑定原快照。

## 需求与验收追踪

| 任务 | PRD 需求 | 交付内容 | 可复现验收 |
|---|---|---|---|
| V01-01 本地导入 | IMP-01、IMP-04 | 路径校验、来源记录、文件数量和大小限制、忽略规则、只读扫描 | 正常目录创建记录，非法或不可读路径返回明确错误，扫描不执行项目脚本，符号链接及路径穿越按边界规则处理 |
| V01-02 源码快照 | IMP-02 | Git clean、Git dirty、非 Git 标识，不可变文件副本与内容哈希 | 源码修改产生可区分快照，重导入相同内容复用有效版本，旧快照内容与位置保持稳定 |
| V01-03 Java 索引 | EXP-01、IMP-03 | 包、类、接口、方法、注解、范围、重载身份、文件级错误 | 固定样本逐项核对符号和行号，一个语法错误文件不阻止其他文件产出结果 |
| V01-04 关系证据 | EXP-02 | 继承、接口实现、可确定的静态引用与调用，证据位置及状态 | CONFIRMED、INFERRED、UNRESOLVED 可查询，确认关系可定位证据，多实现与缺失依赖有明确说明 |
| V01-05 索引任务 | IMP-03 | 状态、进度、错误、取消、重试、同快照去重 | 重复及并发请求无重复有效符号，部分结果可查看，失败可恢复，取消与发布结果保持一致 |
| V01-06 源码浏览 | EXP-01、EXP-02 | 项目和快照选择、文件树、只读源码、路径与符号搜索、局部关系和证据跳转 | 搜索重载方法能区分结果，从符号或关系打开同一快照的正确文件及行号，错误与未解析原因可见 |
| V01-07 阶段验收 | 全部上述需求 | 可运行版本、运行说明、测试与验收报告 | 记录样本版本、规模、耗时、资源测量方法、失败项、已知限制及真实项目核对结果 |

## 必须保留的不变量

- 文件、符号、关系和任务归属于明确项目与快照。
- 符号身份区分类、嵌套类型和重载方法。
- 索引只读取固定快照，重建结果不会改变历史源码。
- 每条已确认关系保留可回溯的证据位置和分析来源。
- 重试、取消、并发与进程中断不会发布混合版本的索引。
- 导入与索引不执行被导入项目的代码、构建脚本或测试。
- 用户输入的路径和 API 引用均须校验访问范围。

## 验收样本

准备包含事务方法、重载、继承、多实现接口、缺失依赖和语法错误的小型固定样本，分别覆盖非 Git、Git clean 和 Git dirty。预期符号、位置及关系状态在实现前记录。

真实 Spring Boot 项目的路径及固定版本尚未提供。EquipOps 在原文中属于候选，待用户指定后用于真实项目验收。合成样本结果与真实项目验收分别记录。

## 实施决策

- 部署方案建议为本地单用户，服务绑定回环地址。
- 用户已确认 React + TypeScript、Spring Boot、JavaParser 和本机 MySQL 8.0 路线。
- 前端细节建议使用 Vite 与只读 Monaco Editor。
- 后端细节建议使用 Symbol Solver、Flyway 与 JDBC 数据访问。
- 源码快照建议存储于 CodeAtlas 专用数据目录，元数据及索引存入数据库。
- 具体依赖版本、解析能力和运行兼容性通过受控验证后记录 ADR。

完整设计见 docs/superpowers/specs/2026-11-13-v0.1-design.md，用户已批准。实际实现与待验收项见 docs/reports/v0.1-acceptance.md。
