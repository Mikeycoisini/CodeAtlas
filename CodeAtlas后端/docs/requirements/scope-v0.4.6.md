# V0.4.6 代码修改 AI 辅助反馈

依据 PR-04 P1 与审计 2.4。

| 需求 | 交付 |
|---|---|
| 实践提交 AI 反馈 | 新端点 `POST /api/practice/submissions/{id}/ai-context`，操作 `PRACTICE_FEEDBACK` |
| 上下文范围 | 冻结任务目标/约束/验收、代码差异、用户外部测试报告、任务来源与未执行代码限制 |
| 授权链路 | 复用预览、ALLOW/DENY、取消、15 分钟有效期、模型指纹与幂等生成 |
| 反馈内容 | 优点、待改进、说明、建议结论（PASS/PARTIAL/NEEDS_WORK/UNSURE）、引用校验、不确定项 |
| 边界 | AI_ASSISTED，仅建议；不改规则判分、测试报告、学习证据、掌握状态或原提交 |
| 明确不做 | 系统自动执行测试、自动采纳 AI 结论、多用户评审、报告附件解析 |
