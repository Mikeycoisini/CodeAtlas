# V0.4.5 代码实践成果关联知识证据

依据 V04-03、KN-01、MEM-02 与审计 2.5。

| 需求 | 交付 |
|---|---|
| 代码提交关联知识 | 新增 `PRACTICE_SUBMISSION` 证据来源；仅成果关联，不单独计入掌握 |
| 测试报告关联知识 | 新增 `PRACTICE_TEST_RESULT` 来源；PASSED 正、FAILED 负、ERROR/TIMEOUT 不计能力 |
| 掌握规则 | `EVIDENCE_V3`；两次**不同提交**的用户报告通过实践测试可达到 SUPPORTED（同一提交多份报告只计一次） |
| 进度展示 | 实践通过次数、提交摘要、报告状态/方法/环境/内容和限制说明 |
| 入口 | 代码练习面板“关联代码提交到知识”“关联该报告到知识” |
| 兼容 | 复用现有证据 API、幂等、撤回、知识版本与历史；无新 API、无迁移 |
| 明确不做 | 系统自动执行测试、把用户报告当系统验证、提交即掌握、多用户评审 |
