# V0.4.3 关系人工修正

依据 PRD EXP-04 P1。

| 需求 | 交付 |
|---|---|
| 关系修正 | 源码页关系卡片提交“修正关系 / 标记不成立 / 标记存疑” |
| 修正来源留存 | 理由必填，可选来源；记录结论、修正类别/目标、时间和代次 |
| 原始分析保留 | 只追加 `relation_corrections`，不改写 `relations`、证据状态或图边 |
| 并存查询 | 关系列表返回原始值与 effective 值、最新修正和历史；图谱证据显示对应修正 |
| 幂等 | 复用 `MutationService`；同键同内容返回原记录，同键异内容 409 |
| 明确不做 | 修改分析器输出、删除历史、多人作者/审批、修正影响图聚合 |
